# Security policy

This repository distributes reference instructions and local Python utilities. It does not operate a hosted service or validate application security automatically.

Report vulnerabilities privately through the repository's GitHub **Security → Report a vulnerability** feature when enabled. If unavailable, ask the maintainer for a private reporting channel without posting exploit details or credentials in a public issue. Maintainers should enable private vulnerability reporting before public release.

Include the affected version, minimal synthetic reproduction, expected/actual behavior and proposed mitigation if known. Do not upload customer data or live secrets. Version 1.0.x is the initial maintenance line; no response-time guarantee is offered.
